Entry for the [make.fun](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) competition "Monday, Reviewed in One Line".

## Entry

> ★☆☆☆☆ Monday: arrived 40 minutes early, brought three meetings I never agreed to, and left at 6 with my inbox heavier than it found it.

## How it works

`main.py` (Python 3.13, stdlib only) writes the one-line review to `entry.txt` in the output directory, then verifies the file on disk byte-for-byte.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 -P -s main.py
```
